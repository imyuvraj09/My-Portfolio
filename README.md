# Yuvraj Singh — AI & ML Portfolio

Personal portfolio website for **Yuvraj Singh** (AI & ML Student at MCKV Institute of Engineering).

## 🚀 Live Features
- **Hero & About Me**: Background, research interests, and resume download.
- **Education**: Detailed academic achievements & CGPA highlights.
- **Experience**: Research fellowships, internships, and technical community roles.
- **Projects**: Machine learning, computer vision, and AI applications.
- **Skills**: Technical stack across Python, PyTorch, TensorFlow, BigQuery, and Web Technologies.
- **Contact & Socials**: Interactive contact form with server handling, plus verified links to LinkedIn, GitHub, LeetCode, HackerRank, and ORCID.
- **Theme**: Dark / Light theme toggle with automatic system preference detection.

## 💻 Running Locally

To run the portfolio website locally without external build dependencies:

```bash
node server.js
```

Open [http://localhost:5175](http://localhost:5175) in your browser.
